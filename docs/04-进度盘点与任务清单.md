### 2.2 三层接口（留给全队的“安全插槽”）

| 层 | 文件 | 说明 |
| --- | --- | --- |
| 类型 | src/lib/types.ts | Task / Question / SchoolInfo / LostFound + 全部枚举 |
| 数据层 | src/lib/data/*.ts | 页面取数唯一入口；接 Supabase 只改内部实现 |
| HTTP | src/app/api/** | 9 个路由文件、11 个处理器，与接口契约一一对应 |

已实测通过的调用链：

~~~text
GET  /api/tasks                   → 列表（支持 q / category / status）
POST /api/tasks                   → 发布（校验 title/description/category/location/contact）
GET  /api/tasks/:id               → 详情
PATCH /api/tasks/:id/status       → 状态流转
GET/POST /api/questions           → 答疑
GET  /api/school-info             → 信息库
GET/POST /api/lost-found          → 失物
POST /api/internal/archive|crawl|digest → 内部任务（配了 CRON_SECRET 才校验）
~~~
