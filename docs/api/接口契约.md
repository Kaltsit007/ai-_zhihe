# 接口契约 v0

> **实现状态（2026-11-24）**：下表全部接口已有最小内存实现，可用 curl 实测。
> 路径、字段、枚举以此文档为准；改之前先在这里改，再通知全员。

统一返回：

~~~json
{ "data": null, "error": null }
~~~

错误：

~~~json
{ "error": { "code": "TASK_NOT_FOUND", "message": "委托不存在" } }
~~~

## 委托

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/tasks | 列表，支持 category、status、q、bbox |
| POST | /api/tasks | 发布委托 |
| GET | /api/tasks/:id | 详情 |
| PATCH | /api/tasks/:id/status | 接单、完成、取消、归档 |

字段：

- category：team、carpool、moving、volunteer、club、other
- status：pending、in_progress、completed、cancelled、archived
- location_name、lat、lng、deadline、contact、images

## 内部任务

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | /api/internal/archive | 归档，带 CRON_SECRET |
| POST | /api/internal/digest | 机器人生成并发送汇总 |
| POST | /api/internal/crawl | 触发爬虫 |

约定：

- 登录接口用 Supabase JWT。
- 内部接口用 CRON_SECRET，不暴露给前端。
- 字段一旦确定，D1 后不随意改名；要改先改本文档并通知全员。
