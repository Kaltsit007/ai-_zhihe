# 群机器人

目标：每天 20:00 把当天新增和未解决的失物招领汇总发到测试群。

## P0 范围

- 一个测试群，一个 webhook。
- 每天一次定时，管理页可手动触发。
- 发送失败时写入 bot_digests，管理页可复制重发。
- 不接复杂平台适配，不处理私聊。

## 环境变量

- BOT_WEBHOOK_URL

## 汇总格式

~~~text
【今日失物招领】
新增 3 条 / 未解决 5 条

1. 丢失：黑色耳机盒
   地点：图书馆二楼
   时间：11-24 18:20

2. 拾到：校园卡
   地点：一食堂门口
   时间：11-24 12:10

完整列表：/lost-found
~~~

## 约定

- 不发送联系方式到公开群，详情页查看。
- 发送失败要留档，不静默失败。
- webhook 只放环境变量，不进 Git。
